# Agent 种子 A/B 结果（cJSON 1.7.10）

目的：验证“Agent 生成结构化种子”是否缩短首次崩溃时间。

| 策略 | 种子数 | 执行数 | 崩溃 | 首次崩溃耗时(s) |
|---|---:|---:|---:|---:|
| 纯 fuzz | 4 | 10 | 2 | 0.19 |
| Agent 种子 | 10 | 8 | 2 | 0.17 |

Agent 额外生成 6 个 JSON 种子：长字符串、`\u0000`、未闭合注释、长数字、反斜杠、数组骨架。

## 结论

- 两者都在 2 次执行内命中，**Agent 种子没有显著优势**；
- 原因是 cJSON_Minify 的读越界离种子太近，纯字节变异也能立刻触发；
- 这个结果如实保留，不把 Agent 包装成“提升命中率”的功臣。
