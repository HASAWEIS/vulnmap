## 2. PoC 是怎么来的（不靠猜）

1. 从 vul 镜像读 `/src/wget2/src/options.c`（468–498 行）；
2. `set_char_prefix` 按 `strlen(val)*2+1` 分配，先写 1 字节 prefix；
   value 里每个 `,` 写 2 字节（逗号 + prefix）；
3. 全逗号时 `dst = 起始+2n+1`，末尾 `*dst = 0` 落在下标 `2n+1`，越界 **1 字节**；
4. 输入只需一行：`include_directories=,`。

实测帧与 ARVO 记录一致：

```text
#0 set_char_prefix /src/wget2/src/options.c:492
#1 parse_included_directories /src/wget2/src/options.c:502
#2 set_long_option /src/wget2/src/options.c:2341
```
